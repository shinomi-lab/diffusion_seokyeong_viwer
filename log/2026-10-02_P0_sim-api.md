## つまずきと対処
- `cargo fmt --all` がコピーした `core`・`runner` を整形してしまった → 元から再コピーして復元。以後は `cargo fmt -p sim-api` のみ。
- `runner` の既存テストが `../test/` を参照して失敗 → `test/` を（`twitter_dataset.txt` を除いて）コピー。
- wasm32 で `getrandom` のバックエンド未指定エラー → `.cargo/config.toml` と `sim-api` の wasm32 限定依存を追加。
- `batch_toml` が結合文字を `\u{3099}` と出力し TOML として不正 → 自前の文字列エスケープに変更。
- `clippy` が `core` のコピーの既存警告で失敗 → `--no-deps` を使用。
