## 作ったもの（`web/`）
- 足場: Vite 8 + React 18 + TypeScript（厳格）+ zustand + uPlot。`src/worker/{protocol,sim.worker,client}.ts`（型付きの要求/応答、transfer）。
- `NetworkView`: 自前の WebGL2（1 回の `drawArraysInstanced`、円・四角・左右半分塗り・IP・現在のウェーブの輪）＋ Canvas2D（リング・辺・扇形セル・強調・縮小地図）。パン・ズーム・クリック・Shift ドラッグの範囲選択。1 万ノード超は全体図（扇形セル、リング表、到達不能の枠）から始まり、展開・「全体図に戻る」。
- 再生: `stateAtWave`、再生/一時停止/コマ送り/速度/スキップ、再生中は発信不可、内部活性の「累積/このラウンドのみ」。
- 操作パネル: グラフ設定、シナリオ設定、機構 M1〜M5（`paramSpecs` から自動生成）、プリセット 3 種、IP 選択（次数/PageRank/VC CSV）、メッセージパレット、発信、設定変更時の確認パネル。キーボード操作。
- グラフ類: `RoundChart`、`NodeDetail`（ノード/ノード群。縦軸は上限なしの自動拡張）。
- 書き出し: シナリオ JSON・ラウンド別 CSV・イベント CSV・設定の保存/読込。`docs/p1-compare.md` と `npm run compare`。
- `spec/ui-tokens.json`（共通の色・形・寸法）。

## つまずきと対処
- Chrome 拡張が未接続 → puppeteer-core（ブラウザのダウンロードなし）で Mac の Chrome を操作。
- Enter が、フォーカス中の別ボタンの動作になり発信されなかった → 「発信」ボタン以外では発信にした。
- ノードのクリックが当たらないように見えた → テストの座標のずれ（IP の実位置が 9px 違った）。許容半径を max(半径×1.5, 8px) に広げた。
- 展開した部分集合に無いノードへの強調辺が描かれた → 両端が表示中のときだけ描くようにした。リング名が重なる → 間隔 16px 未満は間引く。
- 再生のたびに背景レイヤー（3 万本の辺）まで描き直していた → レイヤーごとに更新条件を分離（ソフトウェア GL で 3 → 7.5 fps）。
- JSON の浮動小数点の比較は `serde_json` の `float_roundtrip` が必要（P0-11 から）。

## 限界・未実施
- **N03（1 万ノードで 60 fps）は未確認**。GPU なしのソフトウェア GL では 1 万ノード再生中に約 7.5 fps（JS 側の描画は 1 ms 未満）。実 GPU で測る。
- Twitch 規模の実データ、F09（巻き戻し・分岐）、F12 の画面、F13（2 画面比較）、F15（動画）は P3。
- 3 水準の比較は 100 ノード・1 回の実現のため、既定の強さ（Q3）の調整にはまだ使えない（MC 平均が必要）。
- Q5（κ のタイミング）・Q10（既定の2倍）は確定済み。
