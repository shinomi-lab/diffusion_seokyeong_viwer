# P1 の完了判定: 3 水準の流し比べ（設計書 9.8）

「すべて無効（現行）」「既定」「既定の2倍」の 3 水準で、**同じ IP・同じ系列・同じシード**を流し、M1〜M5 の既定の強さ（要件書 6.6）を確認・調整する。

## 手順（画面で行う）
1. `cd web && npm run wasm && npm run dev` で起動し、ブラウザで `http://localhost:5173/` を開く（`?sample=1` を付けると `test/100random.txt` を自動で読み込む）。
2. 左の「グラフ」で **サンプル（100random）を読み込む**（または任意のグラフを選ぶ）。
3. 「シナリオ設定」を固定する（例: 受信確率 0.6、**計画ラウンド数 20**、母集団シード 0、拡散シード 0）。
4. 「IP の選択」で同じノードを選ぶ（例: 次数順の 1 位）。
5. 「拡張機構」のプリセット（**現行（すべて無効）** → **既定** → **既定の2倍**）を順に選び、そのたびに「設定を適用」を押す（履歴が消える確認が出る）。
6. 各水準で同じ系列を発信する（例: `0135024501` = キー `1 4 2 6 1 3 5 6 1 2` を押して Enter）。再生は「⏭」でスキップしてよい。
7. 各水準の終わりに、ツールバーの **シナリオ記録 (JSON)** と **ラウンド別 (CSV)** を保存する（ファイル名に水準名を付ける）。
8. 保存した JSON の `config` は、「設定を読み込む」で読み戻せる。同じ IP・系列を発信すると、同じ結果が再現される。

## 手順（自動）
`cd web && npm run compare` で、同じ手順を sim-wasm で実行し、`docs/p1-compare/` に記録（`<水準>.scenario.json`、`<水準>.rounds.csv`、`summary.md`）を書き出す。`npm test` では記録を書かずに次を検証する。

- 記録 JSON の設定から同じ系列を再現すると、ラウンド別 CSV が一致する。
- 「すべて無効」は、機構なしの設定（`{"receipt_probability":0.6,"horizon":20}`）と結果が一致する（INV-02 の画面側の確認）。
- 水準が違えば結果が違う（機構が効いている）。
